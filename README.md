# EcoConciencia

Sitio web educativo sobre problemas medioambientales y acciones cotidianas para cuidar el planeta. Incluye navegación interna, contenido multimedia, tarjetas de soluciones, reseñas ilustrativas y formulario de contacto.

## Archivos
- `index.html`: estructura semántica y contenido de la página.
- `styles.css`: estilos, Flexbox, Grid y diseño responsivo.
- `README.md`: descripción e instrucciones básicas.

## Cómo visualizar
1. Descargá o descomprimí la carpeta del proyecto.
2. Abrí `index.html` en un navegador.
3. La página utiliza Google Fonts e imágenes/video externos, por lo que esos recursos requieren conexión a internet.

## Activar el formulario de Formspree
1. Creá un formulario en [Formspree](https://formspree.io/).
2. Copiá el identificador que te proporciona Formspree.
3. En `index.html`, buscá `https://formspree.io/f/TU_ID_DE_FORMSPREE` y reemplazá `TU_ID_DE_FORMSPREE` por tu identificador real.
4. Probá el envío desde el sitio y seguí las instrucciones de verificación que Formspree solicite.

El formulario está preparado para enviar nombre, correo electrónico y mensaje mediante `POST`; no enviará correctamente hasta que configures tu ID real de Formspree.

## Requisitos incluidos
- Etiquetas semánticas `header`, `nav`, `main`, `section` y `footer`.
- Navegación interna con lista desordenada.
- Formulario con campos requeridos y validación básica del navegador.
- CSS externo y Google Fonts.
- Fondo con imagen y degradado.
- Tarjetas de soluciones con Flexbox.
- Sección de reseñas con CSS Grid.
- Media Queries para navegación y sección de contacto.
- Imágenes con texto alternativo e iframe de video adaptable.

## Nota sobre el contenido
Las reseñas son ficticias y se incluyen únicamente como ejemplos de diseño. Las imágenes y el video se cargan desde servicios externos.
